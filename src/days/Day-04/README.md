# React Search & Filter Products + Form Validation

A beginner-friendly React application featuring two projects built using React Hooks, JavaScript, and Tailwind CSS.

## 🚀 Projects Included

### 1. Search and Filter Products

Features:
- Search products by product name.
- Filter products by category.
- Filter products by price.
- Display products dynamically using `map()`.
- Filter matching products using `filter()`.
- Display the total number of matching products.
- Show a message when no products are found.
- Responsive product card layout.

### 2. Registration Form Validation

Features:
- Full name input validation.
- Email format validation.
- Password validation.
- Confirm password validation.
- Display error messages for invalid inputs.
- Display a success message after successful submission.
- Controlled inputs using React `useState`.
- Handle form submission using `onSubmit`.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- Tailwind CSS
- HTML5
- JSX

## 📚 React Concepts Practiced

| Concept | Usage |
|---|---|
| `useState()` | Manage search, filters, and form data |
| `map()` | Display product cards |
| `filter()` | Search and filter products |
| `onChange` | Handle input changes |
| `onClick` | Handle button events |
| `onSubmit` | Handle form submission |
| Controlled Inputs | Manage form field values |
| Conditional Rendering | Display errors and success messages |
| `preventDefault()` | Prevent browser page refresh |
| Array Methods | Update and filter data |



## ⚙️ Installation and Setup


### 1. Install dependencies

```bash
npm install
```

### 2. Install Tailwind CSS

For Tailwind CSS v4 with Vite:

```bash
npm install tailwindcss @tailwindcss/vite
```

### 3. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.
